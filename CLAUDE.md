# KAAL

KAAL is a scroll-driven cinematic Janmashtami experience. The rendering foundation is React Three Fiber. Until production GLBs are supplied, the hero uses an isolated, recognizable Krishna-compatible procedural stand-in; this is not the final character asset.

## Development

```bash
npm install
npm run dev
npm run build
```

Press `E` for engineering mode. Number keys `1` through `7` jump to story chapters.
